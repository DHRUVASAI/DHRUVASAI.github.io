## 💻 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (version 20 or higher recommended)
- `npm` or `pnpm`

### 1. Clone the repository
```bash
git clone https://github.com/DHRUVASAI/dhruva-sai-portfolio.git
cd dhruva-sai-portfolio
```

### 2. Install dependencies
```bash
npm install --legacy-peer-deps
```

### 3. Configure environment variables (Optional for local Gemini chat)
Create a `.env` file in the root directory:
```env
GEMINI_API_KEY=your_google_gemini_api_key_here
VITE_GEMINI_API_KEY=your_google_gemini_api_key_here
```

### 4. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) or [http://localhost:5173](http://localhost:5173) in your browser.

### 5. Build for production
```bash
npm run build
```

## 🌐 Deployment & Cloudflare Setup

The site is continuously deployed via **GitHub Actions** to GitHub Pages and proxied through **Cloudflare** for edge caching, SSL/TLS, and DDoS mitigation:

```
[Visitor Browser]
       │
       ▼
[Cloudflare Edge CDN] ─── (Universal SSL + Edge Cache + Brotli)
       │
       ▼
[GitHub Pages Origin] ─── (Vite React 19 Build Artifact)
```

- **Apex Domain**: `https://vudatha-dhruva-sai.me/`
- **DNS**: Cloudflare Proxied `A` & `CNAME` records pointing to GitHub Pages.
- **SSL/TLS**: Cloudflare Full (Strict) with HSTS and automatic HTTPS rewrites.
